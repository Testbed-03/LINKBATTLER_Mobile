# LINKBATTLER_Mobile
Android版リンクバトラー1.20

LINKBATTLER Mobile
本アプリは、Pleiades Company様が開発したSLG、「LINK BATTLER ver1.20」をAndroidで動作するよう改造したものです。

起動方法
LINK_BATTLER120.bat をダブルクリックしてください。

終了方法
・ブラウザを閉じてください。

アンインストール方法
・ファイルを展開したフォルダごと削除してください。

セーブデータについて
本作ではブラウザのLocalStorageを使用してゲームデータを保存しています。
アップデートした場合もデータは引き継がれます。

著作権について
このファイルに含まれるものは全て、Pleiades Company様が著作権を所有しています。
これらの内容を他の作品の素材として利用することは禁止します。
